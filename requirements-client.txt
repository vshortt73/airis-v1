# ============================================================================
# Airis Client Box - Minimal Requirements
# ============================================================================
#
# CPU-only machine that runs the FastAPI server, PostgreSQL client, MCP tools,
# and embedding generation. Does NOT run inference, TTS, STT, vision models,
# or any GPU-accelerated services. Inference is handled by a remote facility
# server (sglang/llama.cpp) reached via HTTP.
#
# Install:
#   pip install -r requirements-client.txt
#
# For torch CPU-only (saves ~2GB vs full CUDA build):
#   pip install torch --index-url https://download.pytorch.org/whl/cpu
#   pip install -r requirements-client.txt
#
# Note: Install torch FIRST with the CPU index URL, then install this file.
#       pip will skip torch if it's already installed at a compatible version.
#
# Generated from import analysis of: app/, core/, database/, inference/,
# backend/knowledge/, backend/memory/, mcp_servers/, services/
#
# Known issue: app/api/routes_tts.py has top-level imports of whisperx_mapper
# and wav2vec2_aligner which pull in whisperx and torchaudio. These modules
# need conditional/lazy imports for client-box compatibility. Until then,
# routes_tts lip-sync features will fail gracefully (TTS proxy still works).
# ============================================================================
